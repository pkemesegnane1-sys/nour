·Ressources : la bibliothèque de travail

Un développeur professionnel ne sait pas tout : il sait où vérifier en dix secondes. Cette liste est courte parce qu'elle est triée — la documentation officielle d'abord, deux ou trois ouvrages par langage, et rien d'autre. Tout ce qui est « formation vidéo à 997 € » ou « la méthode secrète pour être senior en 30 jours » est hors liste, volontairement.

Les livres qui valent leur prix

JavaScript

You Don't Know JS Yet (Kyle Simpson, gratuit en ligne) — la sémantique : types, portée et fermetures, this et classes, et l’asynchrone. Effective JavaScript (David Herman) — soixante-huit items courts. JavaScript: The Definitive Guide 7e (Flanagan) — l'ouvrage de chevet.

Node

Node.js Design Patterns (Casciaro, Ippolito) — streams, concurrence, modules, architectures. Le seul livre Node qu'on relit deux fois.

PHP

PHP 8 Objects, Patterns, and Practice (Matt Zandstra) — la POO et les patterns en PHP réel. PHP: The Right Way (en ligne) — l'état de l'art communautaire, court et à jour.

Java

Effective Java 3e (Bloch) — quatre-vingt-dix items, à lire un par jour pendant trois mois. Java Concurrency in Practice (Goetz et al.) — plus vieux, toujours juste. Modern Java in Action — streams et fonctionnel.

Bases de données

SQL Antipatterns (Bill Karwin) — les neuf erreurs qu'on fait tous. Designing Data-Intensive Applications (Kleppmann) — quand tu veux comprendre les transactions, la réplication, le stockage, indépendamment du langage.

Métier

The Pragmatic Programmer (Hunt, Thomas) — la posture. Clean Architecture (Martin) — les limites et la dépendance. Working Effectively with Legacy Code (Feathers) — le vrai quotidien : du code qui existe déjà.

Où pratiquer sans se ruiner la soirée

  • Exercices guidés : Exercism (mentorat humain gratuit sur JavaScript, PHP, Java), javascript.info/tasks, Advent of Code en décembre (deux étoiles = une bonne soirée).
  • Algorithmique : LeetCode ou CodinGame, vingt minutes par jour maximum — l'objectif est d'entretenir, pas de collectionner les badges.
  • Sécurité : PortSwigger Web Security Academy (laboratoires gratuits, du XSS à l'authentification), OverTheWire pour le terminal.
  • Vrais dépôts : GitHub Explore, filtre good first issue dans un projet que tu utilises déjà. Un merge public vaut dix exercices.
  • Veille qui ne mange pas la journée : les release notes de Node, PHP et Java (une par version), php.watch, JavaScript Weekly, PHP Weekly et Inside.java. Deux lectures par semaine, dix minutes chacune.

Astuce

Chapitre après chapitre, chaque encadré Ressources officielles donne les liens spécialisés. La règle de lecture est simple : si tu ne trouves pas la réponse dans la doc officielle en dix minutes, la question est mal posée — reformule-la (quel langage, quelle version, quel comportement attendu, quel message d'erreur exact) et reviens.
